# CampusLab Twin

Prototip i Digital Twin për menaxhimin e laboratorëve universitarë.

## Zhvillimi lokal

Kërkohet Node.js 22 ose më i ri.

```bash
npm install
npm run dev
```

- Klienti: `http://localhost:5173`
- API: `http://localhost:3000`

Konfigurimi i plotë i mjedisit dhe bazës së të dhënave do të dokumentohet në
hapat vijues të CLT-01.
